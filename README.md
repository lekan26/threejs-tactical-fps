A round-based tactical FPS in three.js, two teams, bomb plant and defuse, economy and buy menu, bots that patrol, hold and react, built by an AI agent for make.fun.

## Run it

```bash
git clone https://github.com/lekan26/threejs-tactical-fps
cd threejs-tactical-fps
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
